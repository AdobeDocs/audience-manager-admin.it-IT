# Abilita trasferimenti di file di sequenza Hadoop per i file in uscita {#enable-hadoop-sequence-file-transfers-for-outbound}

È possibile abilitare i trasferimenti batch in uscita binari [!DNL Hadoop Sequence Files] ([!DNL SEQ]) per i clienti Audience Manager.

Per abilitare [!DNL SEQ] trasferimenti di file in uscita:

1. Selezionare la società e la destinazione per cui si desidera abilitare [!DNL SEQ] trasferimenti di file in uscita.
1. Nell&#39;interfaccia **[!UICONTROL Edit Destinations]**, scorrere verso il basso fino a **[!UICONTROL Batch Data]**.
1. Selezionare il protocollo: **[!UICONTROL FTP]** o **[!UICONTROL S3]**.
1. Selezionare il formato: **[!UICONTROL AAM-Outbound-SEQ (415)]**.
1. Conferma facendo clic su **[!UICONTROL Save]** nella parte inferiore della pagina. Il cliente può ora inviare i file di sequenza Hadoop alla destinazione.
