# Creare o modificare un server S3 {#create-or-edit-an-s-server}

Utilizzare la pagina [!UICONTROL Servers] nello strumento di amministrazione di Audience Manager per creare un nuovo server [!DNL S3] o per modificare un server esistente.

>[!NOTE]
>
>È necessario disporre del ruolo [!UICONTROL DEXADMIN] per creare nuovi server o modificare quelli esistenti.

1. Per creare un nuovo server, scegliere **[!UICONTROL Servers]** > **[!UICONTROL Create Server]**. Per modificare un server esistente, fare clic sul server desiderato nella colonna **[!UICONTROL Label]**.
1. Specificare l&#39;etichetta desiderata per il server.
1. Dall&#39;elenco a discesa **[!UICONTROL Protocol]**, selezionare il protocollo desiderato: **[!UICONTROL S3]**.

   >[!NOTE]
   >
   >È consigliabile utilizzare [!DNL Amazon S3] come metodo per ottenere file da e consegnare file ai partner. [!DNL Amazon S3] fornisce una semplice interfaccia per i servizi Web che può essere utilizzata per archiviare e recuperare qualsiasi quantità di dati, in qualsiasi momento, da qualsiasi punto del Web. Per ulteriori informazioni, vedere [Informazioni su Amazon S3](https://experienceleague.adobe.com/docs/audience-manager/user-guide/reference/amazon-s3.html) nella *Guida utente di Audience Manager*.

1. Compila i campi:

   * **[!UICONTROL Account]:** Specificare l&#39;account [!DNL S3] desiderato.
   * **[!UICONTROL Bucket]:** Specificare il bucket [!DNL S3] desiderato.
   * **[!UICONTROL Directory]:** Specificare la directory [!DNL S3] desiderata.
   * **[!UICONTROL Access Key]:** Specificare la chiave di accesso [!DNL S3] desiderata.
   * **[!UICONTROL Secret Key]:** Specificare la chiave segreta [!DNL S3] desiderata.

1. Fare clic su **[!UICONTROL Create]** se si sta creando un nuovo server oppure fare clic su **[!UICONTROL Update]** se si sta modificando un server esistente.
